# Live 3.x source on the Migrate-from-3.x screen

Milestone: M8    Depends on: M8-02 (02a and 02b built, verified and merged), M8-06a, M8-06b (merged)    Size: M (one developer, 2 to 3 days)

Brief made exact against main 99648cc by the architect (team loop step 1, round 0, 2026-11-10). Owner decisions F4 (option B) and F8 (option B) are decided.

## Goal
The user can analyse the connected RabbitMQ 3.x broker from the Migrate-from-3.x screen (source picker, locked source card, file import offered as a button when the user may not export), starts it from the 3.x connection popup, and sees the navigation reason once, not under every disabled item (F4). The 3.x pill on a profile card shows only while that profile is Connected (F8).

## Why
Spec "Migrating from RabbitMQ 3.x (M8)", decision 1 (live source or file), `docs/tasks/M8-06-report-and-review-ui.md` cut table. M8-02 built the live read (`analyseLive`, `DefinitionsSource`); nothing on screen uses it yet.

## Decided signatures (all in `core` unless said)

Types (`core/migrate3x`, new file `LiveSourceOnScreen.kt`):

```kotlin
enum class SourceKind { File, Live }

/** What the screen may read live right now; null = no readable 3.x connection is held. Read only: DefinitionsSource has no write method. */
interface LiveSourceProvider {
    val current: StateFlow<DefinitionsSource?>
    companion object { val None: LiveSourceProvider }          // current = MutableStateFlow(null), the default of tests and of a screen without a connection
}

sealed interface SourceOption {
    val label: String
    data object File : SourceOption                             // label "Definitions file"
    data class Live(val connectionName: String) : SourceOption  // label "Live connection: <name>"
    data class LiveDisabled(val reason: String) : SourceOption  // label "Live connection", reason = MigrateFromThreeTexts.LIVE_NOT_AVAILABLE
}

/** [selected] is Live only while a Live option is offered (a vanished 3.x connection turns it back into File). */
data class SourcePicker(val selected: SourceKind, val options: List<SourceOption>)
```

Not a `fun interface`: the picker must follow the connection while the screen is open (the user may connect from the chip popup), so the provider is a `StateFlow`. The real one is built in core, so it is unit tested without desktopApp:

```kotlin
/** core/connections: Connected link + held StreamSource + session status Done(MigrationSource) -> that source's definitionsSource, else null. */
class HeldLiveSourceProvider(active: ActiveConnection, session: ConnectionSession, scope: CoroutineScope) : LiveSourceProvider
internal fun liveSourceOf(link: LinkState, source: StreamSource?, sessionState: SessionState): DefinitionsSource?
// the pure rule: link is Connected(name), source != null, sessionState.current?.name == name and sessionState.current.status is Done(MigrationSource)
// ("session status" = `sessionState.current.status`, the status of the CURRENT session connection (step 5 fixed this wording: earlier text said `statuses[name]`; the two agree because `SessionState.current`'s status is always the one in `statuses`)). A name mismatch between link and session gives null.
// Test to add to LiveSourceProviderTest: link Connected "a", session current "b" with Done(MigrationSource) for both, result null.
```

## Design notes
State in, events out; decisions (which options, which reason, which state, which card text, which pill) in `core`, composables thin. The held connection is still one (D1): the picker never offers to connect, it only reads the held connection through `LiveSourceProvider`. The analysis lives in `AnalysisHolder`, not in the view model. The live fetch can take up to 5 s per vhost with a fresh queue (02a bound): `LoadingLive` has Cancel (`cancelLoading()`). The pause of the storage-version scan is `liveSourcePause` inside `ActiveConnection` (already wired in `guardedSource`); this task passes nothing and never calls `delay` itself. Broker faked: `FakeThreeXReads` behind the real `LiveDefinitionsSource`; no real broker in this task (`RealBrokerM8LiveSourceTest` stays green, untouched).
