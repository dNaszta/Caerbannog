Closing: the close button in the block header, or Escape; the row is then not selected. Choosing another row replaces the detail. Switching tab or virtual host closes it.

Banner reasons above the tabs (one banner drawn: the first that applies, in this order)
1. Connection level Read-only (T5; only at that level). 2. No configure permission on the connection's virtual host (the banner at the top of this page, id banner-no-configure; drawn only when the level is NOT Read-only, at Read-only reason 1 replaces it). 3. Declared, not confirmed, or permissions unreadable (NotReadable). 4. Another virtual host (R6). 5. Nothing to say: no banner. On another virtual host reasons 2 and 3 are not shown (the check looked at the connection's own virtual host only); reasons 1 and 4 are. The view model keeps every reason in a list; the screen draws the first.
