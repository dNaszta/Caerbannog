Allow full control?
Full control lets this app delete topology (queues, streams, exchanges, bindings, policies) on this connection and run migrations with destructive actions. This is only your own ceiling for this connection: the broker's permissions still apply, and the app never reads, gets or purges queue messages.
Dialog shown when Full control is picked and was not already selected. Cancel, Esc or a click outside keep the previous choice. The choice is saved only on Save.
Migration history could not be updated (M5-08c)
A profile keeps its applied-migrations history under its name. Renaming or deleting the profile moves or removes that history FIRST; if that fails the profile is left exactly as it was and this banner shows above the buttons of the edit panel (Save or Delete profile), in the same place as "A connection named ... already exists". The delete confirmation dialog closes before the banner appears.
