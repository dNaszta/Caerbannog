States and rules (built from this list, M2-06)
Opening: the name cell of a row in the stream list is a link that opens this screen (back arrow returns to the list). Only the "Publishers and consumers" tab exists in M2; the "Messages" tab is drawn for M3 and is not built yet. The drawer keeps Streams selected.
Header: stream name, "Updated N s ago" and Refresh, as in the list. The tab refreshes with the app-wide interval of the connection control, only while this tab is shown.
Loading: the two section frames with "loading..." rows, never a blank page. Not connected / Connecting: "Not connected" or "Connecting...", no sections.
Empty: "There are no publishers on this stream." and "There are no consumers on this stream." (each section on its own; scenario "A stream nobody uses").
Plugin missing: the warning banner above in place of both sections; the header and the last offset still show. The banner is the only thing that goes.
Management tag only (S3b): the info banner above stays on screen even when both lists are empty, so an empty list never reads as "nobody is connected". No management tag (S3a): the message "This user cannot read stream statistics. Ask for the monitoring tag." and no sections.
Client that has just attached: the broker row has no connection name and zero counters for a few seconds. The Connection cell says "unknown", the counters, offset, behind and status cells say "updating" (not 0), and the next refresh replaces them. A consumer row with no messages-behind number from the broker reads the same.
Consumer status: "Caught up" for 0 behind (green), "N behind" (the broker's number, neutral grey, never amber or red) above 0, with a tooltip: "Stored offsets count as messages, so any consumer of a stream where offsets are stored can read a few behind when it has read everything.", "Not active" for a consumer that is not the active one of a single-active group (neutral). Unnamed publisher or consumer: the name cell says "unnamed". Offset is plain digits, other counts grouped (same rule as the list). Last offset on the stream is "unavailable" when it cannot be read.
Stream deleted while open: "This stream no longer exists" and a Back to streams button. Lost connection (D2): banner "Connection lost" with Retry, rows stay dimmed and marked stale. Failed first load: "Publishers and consumers could not be loaded." and Retry.
Row whose broker user is not known: the user line under the connection shows an em dash (—), no word ("unknown" already means "just attached"). Give the dash an accessible name "no user" (aria-label), the visible text stays the dash.
Copy: every value in both tables (reference, connection, counts, offset, behind, status) is selectable and copies as displayed. The jump to a consumer's offset is not drawn: it needs the message browser (M3).
