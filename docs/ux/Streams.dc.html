States and rules (built from this list, M2-05)
Loading: the table frame with "loading..." in the cells that are not known yet, never a blank table. First offset still loading: that cell says "loading..."; first offset that could not be read: "unavailable", the counts stay.
Publishers cell "unavailable" when the user has no monitoring or administrator tag (D8) or the stream management plugin is missing.
Empty broker: no table, "There are no streams on this broker yet." and a Create stream button (disabled without the configure permission).
Denied (no management tag): no table, no filters, the message "This user cannot read stream statistics. Ask for the monitoring tag."
Not connected / Connecting: no table, "Not connected" or "Connecting...".
Failed first load: "The stream list could not be loaded. Check that the virtual host exists and that this user may use it." and a Retry button.
Lost connection (D2): a banner "Connection lost" with a Retry button above the rows; the rows stay, dimmed, marked stale.
Number format: offsets are plain digits (2083999); message counts and other counts are grouped (1,204,000). Retention uses the compact form (7D, 12h). Every value in the table (name, type, retention, counts, offsets, publishers, consumers) is selectable text; copy gives exactly the displayed string. A focused cell copies with the platform copy shortcut. Leader and node are not columns in M2 (no detail panel yet).
